# WukongBench

Автоматический запуск **Black Myth: Wukong Benchmark Tool** (Steam, appid 3132990): два прохода (CPU и GPU),
разбор результатов, отчёт в `results\<время>\report.txt` и `report.json` (+ скриншоты экранов результатов).

## Запуск
    dotnet run -c Release                 # оба прохода
    dotnet run -c Release -- --only cpu   # один проход
    dotnet run -c Release -- --info       # железо + поиск Steam/игры
    dotnet run -c Release -- --dry-run    # применить пресеты без запуска игры

Требования: Windows 10/11, .NET 10 SDK/Runtime, Steam с установленным Benchmark Tool, OCR-язык Windows
(для русской локали игры нужен язык `ru`). Во время прогона не трогайте мышь/клавиатуру и держите окно игры
не закрытым другими окнами — результат считывается захватом экрана.

## Как это работает
1. **Steam/игра**: `steam.exe` и каталог игры находятся через реестр, `libraryfolders.vdf` и `appmanifest_3132990.acf`.
2. **Настройки**: перед запуском правится `<игра>\b1\Saved\Config\Windows\GameUserSettings.ini`
   (`UISettingData`, `sg.*`, `ImageQuality`, `DesiredScreen*`, `ResolutionSize*`). Исходный файл возвращается после каждого прохода.
   - CPU: рендер 25 %, тени/GI/отражения/постобработка/AA/текстуры на минимуме, дальность прорисовки, растительность и эффекты высокие, генерация кадров выкл.
   - GPU: рендер 100 % в нативном разрешении, всё на максимуме, генерация кадров выкл., полная трассировка лучей — только на NVIDIA RTX.
3. **Запуск**: `steam://rungameid/3132990`, ожидание главного меню (OCR), клик по «Тест быстродействия», автоподтверждение диалога.
4. **Результат**: инструмент не пишет результаты в файлы, поэтому экран результатов захватывается и распознаётся (Windows OCR,
   разбор по позициям — не зависит от языка). Берутся средний/макс./мин. FPS, 5-й перцентиль, VRAM и панель настроек.
5. Игра закрывается (с проверкой), ini восстанавливается, печатается и сохраняется отчёт.

Пресеты, шаги запуска, таймауты — в `settings.json`.
